The absolute 6 ms gate is missed by every default-like row (best single run 5.70 ms, others 6.3-8.8 ms) with 6-23 %
background CPU on this machine (other sessions build and run GUI scenarios at the same time); it is the same
renderer-thread-wake load artefact as in M2 acceptance, G1 and G2, and it is recorded, not gated, as the lead ruled.
The relative gate is satisfied, but the run-to-run spread of the default (6.4 to 8.4 ms) is larger than the +0.5 ms
margin, so the comparison has low power. The whole path (Git Bash) is not gated. No M3 code runs on the key to pty write path.
